# 💪 Application de Rééducation Hanche

Application mobile de suivi de programme de rééducation pour la hanche sur 8 semaines (2 phases).

## 🎯 Fonctionnalités

### Phase 1 : Reconstruction (Semaines 1-4)
- ✅ Suivi hebdomadaire de progression
- 💪 Enregistrement des charges utilisées
- ⏱️ Chronomètre de repos intégré
- 🩺 Suivi des niveaux de douleur (0-4)
- 📺 Vidéos démo YouTube pour chaque exercice
- 📊 Tableau de progression visuel
- 🔒 Déblocage conditionnel de la Phase 2

### Phase 2 : Force & Vitesse (Semaines 5-8)
- Débloquée uniquement si Phase 1 complète SANS douleur
- Programme intensifié avec nouvelles séances

### Organisation hebdomadaire
- **Lundi** : Séance A (Force & Poussée)
- **Mardi** : Repos total
- **Mercredi** : Séance B (Jambes & Dos)
- **Jeudi** : Repos total
- **Vendredi** : Séance C (Mobilité)
- **Week-end** : Repos actif & Famille

## 🛠️ Technologies

- React 18 (standalone)
- HTML5 / CSS3
- localStorage pour la persistance
- Design mobile-first responsive

## 📱 Utilisation

1. Ouvre l'application dans ton navigateur
2. Sélectionne ta semaine (S1-S4)
3. Choisis ta séance du jour
4. Valide chaque exercice après l'avoir fait
5. Entre tes charges et niveaux de douleur
6. Utilise le chronomètre pour les temps de repos

## 💾 Données

Toutes les données sont stockées localement dans ton navigateur :
- Exercices validés par semaine
- Charges utilisées
- Niveaux de douleur
- Progression globale

## 🚀 Déploiement

### Vercel (Recommandé)
1. Connecte ton repo GitHub à Vercel
2. Déploiement automatique à chaque push
3. URL personnalisée générée

### Alternative locale
Ouvre simplement `index.html` dans un navigateur moderne.
